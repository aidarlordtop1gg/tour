## Описание
 
Веб-приложение для турагентства. Оно помогает быстро подобрать подходящий тур: пользователь задаёт параметры поиска, смотрит подробную информацию о туре и сохраняет понравившиеся варианты в избранное, чтобы вернуться к ним позже.
 
**Цель проекта:** сделать приложение, где можно подобрать тур, изучить его и сохранить на потом.
 
### Основные части
 
1. **Подбор тура** — поиск и фильтры:
   - страна;
   - даты поездки;
   - диапазон цены;
   - рейтинг отеля;
   - авиакомпания (прямые рейсы);
   - показ количества найденных туров и кнопка «Сбросить всё».
2. **Страница тура** — описание и программа, фотографии, страна и город, даты и количество ночей, стоимость, отель и рейтинг, авиакомпания и багаж, условия (питание и страховка).
3. **Избранное** — список сохранённых туров со счётчиком и кнопкой «Смотреть тур» для перехода на страницу тура.

## Технологии
 
- **Python 3** — основной язык
- **Flask** — веб-фреймворк
- **PostgreSQL** — база данных для туров и избранного
- **HTML / CSS / JavaScript** — интерфейс
- **Git / GitHub** — совместная работа и контроль версий
